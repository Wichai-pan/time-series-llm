## 表1 · 生成保真度 TSG（标准化空间；越低越好）+ 两个地板

| 配置 | walking ACD | running ACD | walking MDD | running MDD | 说明 |
|---|--:|--:|--:|--:|---|
| **同-subject 地板**(train 切两半,5 split) | **2.49±1.47** | **0.93±0.38** | 0.284 | 0.290 | 同分布互比;n~27 噪声大 |
| 跨人地板(106/108 vs 101/102/105) | 1.22 | 1.02 | 0.184 | 0.226 | 含 subject shift(更宽松) |
| clean baseline(同人重建) | 0.165 | 0.498 | 0.266 | 0.297 | |
| gpt2 raw-unified(无修复) | 5.97 | 2.29 | 0.257 | 0.299 | 爆炸 |
| Qwen label-only(无修复) | 1.57 | 2.92 | 0.278 | 0.313 | 不爆炸 |
| **组合最优 SDForger(LLM)** | **1.04**(5-seed ±0.41) | **0.69**(±0.14) | 0.169 | 0.206 | 我们的方法 |
| **高斯系数 baseline(LLM→高斯,同 FICA 解码)** | **1.07** | **0.60** | **0.158** | **0.191** | **≈ 甚至优于 LLM;也不爆炸(absmax 3.4/4.0)** |

> 🔴 **最关键的诚实发现(回应审计"无生成式 baseline")**:把 LLM 换成"**对 FICA 系数拟合一个高斯、采样、走同样的线性解码**"这个 trivial 生成模型,TSG **持平甚至略优于** SDForger(高斯 MDD 0.158/0.191、running ACD 0.60 都更低),且**同样不爆炸**。→ **在无条件逐动作生成上,LLM 相对"高斯系数先验 + 解码"没有可测增益**;保真度的功劳在 **FICA 表示 + 修复**,不在 LLM。LLM 唯一可能的增值在**可控/条件生成(=课程 prompt-design 主题,表2)**。
> ⚠️ 两个生成器都**低于两个地板**:地板每半仅 ~27 窗(ACF 估计噪声大,±1.47),生成器采样多、解码平滑 → 聚合 ACF 匹配更好。**这些距离指标在此样本量下被采样噪声主导,不能据此判 LLM 捕获了高斯之外的结构**。数字源需统一(单跑 clip 0.74/0.74 vs 5-seed 1.04±0.41/0.69±0.14)。

## 表2 · Prompt 设计 = 模型 × 编码（数值遵守度 Spearman）

| | 真实数值 | 粗档 bins | 类别 ×1/×3(唯一 backend-matched) |
|---|---|---|---|
| **gpt2(124M)** | vLLM 下 **0/256 可解析**(composite 脆) | 0/256 | 0.94 |
| **Qwen-1.5B** | **3-seed pooled ρ=0.36±0.13**(0.20/0.38/0.51;v2 0.58,accept 0.75) | **0.10**(seed42) | 0.96 |
| **条件高斯基线**(非 LLM:按 max 分箱+每箱高斯采样) | **pooled 0.413**(walk 0.597/run 0.230) | — | — |

> ✅ **【硬】给定 Qwen,真实数值编码 ≫ 粗档**:3-seed 0.36 vs 0.10,walking per-label 0.41–0.56 vs bins 0.0003。这是本项目最硬的 prompt-design 结论(编码维度)。
> 🔴 **但可控性也被 trivial 基线追平**:条件高斯(对每个 max-箱拟合高斯采样)pooled ρ **0.413 ≈ 甚至 > LLM 0.36**。→ **在"复现分箱内经验条件"这个指标上,LLM 不占优**。
> ⭐ **关键边界(=研究问题所在)**:条件高斯**只能复现见过的、分箱的条件,不能组合/外推/文本条件化**。LLM **唯一未被本指标测到的潜在优势,正是开放式/组合式 prompt 条件化**——这就是课程 prompt-design 该继续打的战场。负结果**指明方向**,不是否定。
> ⚠️ **gpt2 注脚(改自"产出垃圾")**:gpt2 retry **是 vLLM 后端**(job 35210158/35210159 日志证实,非审计所说 HF),仍 0/256 可解析;但 2026-06-17 另一 composite 的 vLLM gpt2 曾出 73/74 可解析(只是 adherence≈0)。→ 准确说法:**gpt2 可解析输出对 composite 格式很脆,且在任何设置都达不到数值 adherence**(不是"连合法输出都给不出")。
> ⚠️ **"需强模型"降级**:唯一 backend-matched 的 ×1/×3 显示 **gpt2 0.94 ≈ Qwen 0.96(都不遵守)** → 数值可控性**不随模型变强自动出现**;起作用的是**实值编码 + 足够强模型两者叠加**,且 gpt2 在 stat-prompt 缺 backend-matched 对照,严格说"gpt2 能否学实值"**未在公平条件下测过**【provisional】。

## 表4 · 下游 HAR utility（**探针欠功效**）

| 条件 | accuracy | 说明 |
|---|--:|---|
| majority | 0.500 | 随机 |
| real-only | 0.742 | |
| best jitter(steelman σ∈{.05,.1,.2}×2seed) | 0.742 | 调好的 trivial 基线 |
| 高斯系数 baseline real+syn / syn-only | 0.758 / 0.652 | 另一个 trivial 生成器 |
| SDForger real+syn / syn-only | 0.745 / 0.715 | 我们的方法 |

> ⚠️ **诚实解读**:**test n=66,单点 95% 抽样 CI ≈ ±0.11**(Wilson)。所有方法(real-only / jitter 0.742 / 高斯 0.758 / SDForger 0.745)都在 0.65–0.76、**远在抽样噪声内 → 这个 2 类探针没有分辨力,排不了序**。±0.013/±0.029 只是 5 个**生成 seed**方差、**不含 test 抽样**,属虚高精度。
> **【只能说】合成数据下游既不胜出、也未证明等价**(探针太弱);**不拿下游精度当卖点**。

## 一页式结论（诚实分级，会上口径）

> **定位重构(本轮最重要)**:不要把项目讲成"我们做了一个好的 HAR 数据生成器"——它在 TSG 上**被 trivial 高斯打平**、在 HAR 上**与 jitter/real-only 不可分**。要讲成"**用正确的 baseline(高斯/jitter/两个地板/记忆化)严格界定了 LLM 在时序生成里到底加了什么**,并围绕课程主题做了 **LLM 可控性(prompt-design)** 的诚实研究"。这是一个**成熟、可拿高分**的科研故事(对的不是结果漂亮,是方法严谨 + 诚实)。

**【硬结论】**
1. **三个轴全部被 trivial 基线追平**:① 保真度 TSG → 高斯系数 baseline 持平/略优(表1);② 下游 HAR → jitter/高斯/real-only 全在 ±0.11 噪声内不可分(表4);③ **可控性 → 条件高斯 pooled 0.41 ≈/> LLM 0.36(表2)**。→ **LLM 在我们测的任何指标上都没有可测优势**;保真度/不爆炸/不拷贝/分箱可控,trivial 模型都做得到。
2. **这不是否定,而是把研究问题磨锋利**(对 LLM 的公平 steelman):我的高斯是**逐动作拟合**的强基线(已 handle 主要双峰),它会失败、而 LLM 可能赢的有**两个战场**:① **开放式/组合式/文本 prompt 条件化**(生成训练里没出现过的条件)——条件高斯结构上做不到;② **多峰/复杂系数分布**(多动作联合、多通道,**单个高斯拟合不了**)。这俩**恰好对口 prompt-design + SDForger 招牌**,是下一步唯一该打的方向。
3. **编码维度的硬结论(保留)**:给定 Qwen,**实值编码 ≫ 粗档**(3-seed pooled 0.36 vs 0.10,walking per-label 0.41–0.56 vs bins 0.0003);gpt2 在任何设置都不能条件化于数值。

**【provisional / 未坐实】**
- Qwen 实值 ρ≈0.36 有 3 seed 但**无 CI、跨 seed 0.20–0.58 波动**;v2 跑到 0.58。
- "强模型带来可控性/稳定性"**混了后端 + epoch,未隔离容量**;唯一 backend-matched 的 ×1/×3 反而显示 gpt2 0.94≈Qwen 0.96(都不遵守)。

**【只能说"未证伪"，不能说"证明"】**
- 记忆化:只排除**整窗拷贝**;部分/尾部拷贝本探针测不到(跨人分母 + FICA 子空间 confound)。
- Fidelity:距离指标在 n~27 被采样噪声主导,**不能证明 LLM 捕获了高斯之外的结构**。

## 仍缺（按对抗审计重排）

- **【HIGH·新方向】open-ended 条件化才是 LLM 该赢的战场**:in-distribution 分箱可控性已被条件高斯追平(表2)。下一步唯一值得做的是测 **LLM 能否生成训练里没出现过的条件**(组合条件、novel 目标值、文本描述条件)——条件高斯/VAE 结构上做不到,这才是 LLM 可能真正赢、且对口 prompt-design 的地方。设计预注册的 held-out-condition 实验。
- **【已完成对照】**生成式 baseline:高斯系数(表1,保真度)+ 条件高斯(表2,可控性)+ jitter(表4,下游)三个 trivial 基线已全部对过,LLM 均不胜。学习型生成器(TimeVAE/DDPM)可作正式论文的补充对照。
- **【中】**同-subject 地板已补(表1)需正式写入;HAR 改用含 test 抽样的 Wilson CI;修复规则去 selection-on-test。
- **【中低】**多通道/多变量(SDForger 招牌 + HAR 真难点 + embedding_dim:auto bug);LOSO HAR;TSG 差异的统计检验。
