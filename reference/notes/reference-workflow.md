# Reference Workflow

1. 原始论文放在 `reference/papers/`，或继续保留在 `legacy/old-project-files/` 并在 `reference/.agent/source-index.md` 里索引。
2. Copyright-safe 的 source cards 放到 `reference/cards/`。
3. 对项目的影响分析放到 `reference/project-use/`。
4. 只有稳定的 claim、evidence、risk 和 action 才提升到 `memory/`。
5. 不要把长篇原文、长引用或私有反馈复制到 public/collaborator-visible memory。
